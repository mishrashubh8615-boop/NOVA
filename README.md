NOVA is an Voice assistant that open sites.read news and play music that are available in musicLibrary.py. I had build this by geeting inspired by jarvis though it is not that much intelligent but I will upgrade it in future

HOW TO USE: After runing this you have to say nova then it will repsond on saying , for example you want to open youtube so you will say NOVA and then it will respond NOVA initalizing then you have to say OPEN youtube then it will automatically ipen youtube for you

Technologies Used:
1. Python – Main programming language.
2. SpeechRecognition – Recognizes voice commands
3. pyttsx3 – Text-to-speech.
4. PyAudio – Microphone input.
5. Requests – Fetches news/API data.
6. python-dotenv – Manages environment variables.


Installation Guide: Clone the repository using Git: git clone https://github.com/mishrashubh8615-boop/NOVA Or download the repository as a ZIP file from GitHub and extract it.

Install Required Dependencies Open the project folder in VS Code or your terminal and run: pip install -r requirements.txt

Configure Environment Variables

Create a .env file in the project folder.

Copy the contents of .env.example into .env and add your own API key where required. Run NOVA

After completing the setup, run:

python main.py

Make sure your microphone is connected and working before starting NOVA.

That's it! NOVA is ready to assist you.


To run NOVA you can also run NOVA.exe
